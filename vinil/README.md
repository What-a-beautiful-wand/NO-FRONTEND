# Винильчик

Интернет-магазин винила: существующий React + TypeScript + Vite, бэкенд FastAPI и PostgreSQL.

**Полное руководство для разработки фронтенда: [backend/README.md](backend/README.md).** Там описаны все API, JSON-модели, авторизация, поиск, корзина, заказы, административные методы, ошибки, примеры TypeScript/curl, настройки и тесты.

## Запуск

Из папки `vinil`:

```bash
# Только при первой настройке, если .env ещё нет
cp .env.example .env
docker compose up -d --build
```

При отсутствии доступа к Docker используйте sudo. Сайт: <http://localhost:8080>, API и Swagger: <http://localhost:8000/docs>. Для запуска только БД и API: `docker compose up -d --build db backend`.

React-компоненты и стили не изменены. Фронтенд ещё не подключён к каталогу. Бэкенд содержит аккаунты, личное избранное, корзины, заказы с оплатой при получении, администрирование, загрузку обложек и обратную связь.

```text
vinil/
├── frontend/         # Существующий React
├── backend/          # API, бизнес-логика, миграции, твои моки и тесты
├── docker/           # Nginx и Dockerfile фронтенда
├── compose.yaml     # frontend + backend + db, постоянные тома БД/изображений
├── .env.example
├── .gitignore
└── .dockerignore
```

Текущий мок-каталог содержит 9 твоих пластинок. При первом запуске с SEED_MOCK_DATA=true заполняется только пустая БД. Существующий каталог сохраняется. Учётных записей по умолчанию нет; создание администратора описано в руководстве бэкенда.

`docker compose down` сохраняет данные; **docker compose down -v удаляет БД и загруженные изображения**.
